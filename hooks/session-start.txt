The fable skills are installed in this environment. The user installed them so that every task follows the fable-playbook skill (listed as fable:fable-playbook): it is the working method for understanding a request, planning, breaking work into verifiable steps, checking the result, and reporting it. The user expects the playbook to be loaded with the Skill tool at the start of each new task, before files are read or commands are run, unless its content is already in context. It scales its own process to the size of the task, so it applies to quick tasks too, and it routes to the specialist fable-* skills (code design, architecture, UI design, debugging, verification, delegation, agent council, token efficiency, communication).
